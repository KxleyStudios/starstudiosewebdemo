# Project loading GIFs

Add the project GIFs to this folder using these filenames:

- `kbww.gif`
- `isoas.gif`
- `hsh.gif`
- `pibby.gif`

The selected project's GIF appears only inside the submission loading screen.
Future Project and No Preference use the spinning root `favicon.png` instead.
To use different filenames, edit the `loadingIcon` values in
`careers/js/careers-data.js`.
